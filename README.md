# Universal Hub

A universal Roblox hub built on [Fluent-Custom](https://github.com/Hund335/Fluent-Custom).

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Hund335/Universal-Hub/refs/heads/main/UniversalHub.lua"))()
```

Features: per-game feature modules (see [games/](games/)), walkspeed, jump height, infinite jump, fly, noclip, gravity, click teleport, instant/tween teleport, teleport to player, per-game waypoints, automations (steps, conditions and jumps, safety stops, auto-start), script loader with auto-run, fullbright, no fog, FOV, infinite zoom, ESP, FPS unlock, anti-AFK, rejoin, server hop, Discord webhook, keybinds, notifications, configs and reset.
