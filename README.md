# Universal Hub

A universal Roblox hub built on [Fluent-Custom](https://github.com/Hund335/Fluent-Custom).

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Hund335/Universal-Hub/main/UniversalHub.lua"))()
```

Features: walkspeed, jump height, infinite jump, fly, noclip, gravity, click teleport, instant/tween teleport, teleport to player, per-game waypoints, script loader with auto-run, fullbright, no fog, FOV, infinite zoom, ESP, FPS unlock, anti-AFK, rejoin, server hop, keybinds, notifications, configs and reset.
